# CUSTOS-Updates

Automatischer Update-Kanal für [CUSTOS](https://github.com/Sash3107/CUSTOS) (privates Repo).

Dieses Repository enthält **ausschließlich** fertig gebaute Release-Pakete (ZIP + `version.json` je Release) — keinen Quellcode. Es dient als öffentlicher, vom privaten Quellcode entkoppelter Verteilpunkt für den CUSTOS-AutoUpdater (`autoupdater/` im Haupt-Repo).

Releases hier werden ausschließlich automatisiert über `Publish-ToGitHub.ps1` erstellt.
