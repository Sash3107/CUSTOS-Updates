# CUSTOS-Updates

Automatischer Update-Kanal für [CUSTOS](privates Repo).

Dieses Repository enthält **ausschließlich** fertig gebaute Release-Pakete (ZIP + `version.json` je Release) — keinen Quellcode. Es dient als öffentlicher, vom privaten Quellcode entkoppelter Verteilpunkt für den CUSTOS-AutoUpdater.
